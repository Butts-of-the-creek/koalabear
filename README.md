# KoalaBear 🐨

KoalaBear is a modern student housing marketplace built to simplify how university students discover, list, and secure rental accommodation.

## 📌 Overview

KoalaBear connects students with verified landlords, providing a seamless mobile experience for browsing and managing rental listings. The platform is designed to reduce friction in student housing and scale across universities.

## 🚀 Features

* 🔐 Authentication (Firebase)
* 🏠 Browse rental listings
* 🔎 Advanced search and filters
* 📄 Detailed property views
* 📤 Landlord listing uploads
* 👤 User profiles and management

## 🛠️ Tech Stack

* React Native (Expo)
* TypeScript
* Firebase (Auth, Firestore, Storage)
* React Navigation

## 📂 Project Structure

```
src/
  components/
  screens/
  navigation/
  services/
  types/
```

## ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/koalabear.git
cd koalabear
npm install
npx expo start
```

## 🌿 Branching Strategy

* main → production-ready code
* dev → integration branch
* feature/* → individual features

Example:

* feature/auth
* feature/listings
* feature/upload

## 🤝 Contributing

1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Push and open a pull request

## 📈 Vision

KoalaBear aims to become the leading student ecosystem platform in South Africa, starting with housing and expanding into food, marketplace services, and logistics.
